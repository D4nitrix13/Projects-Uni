Unidad III

Programación del Microprocesador

En esta unidad se explica cómo se programa un microprocesador mediante instrucciones de bajo nivel, registros internos y ejemplos básicos en lenguaje ensamblador.

Introducción a la Programación del Microprocesador

La programación del microprocesador consiste en escribir instrucciones que la CPU puede interpretar y ejecutar. En procesadores como el 8086, se puede utilizar lenguaje ensamblador para trabajar directamente con registros, memoria y operaciones básicas.

El lenguaje ensamblador permite comprender cómo trabaja internamente una computadora, ya que muestra operaciones de bajo nivel como mover datos, sumar valores, comparar, saltar a etiquetas y controlar el flujo del programa.

Registros del Microprocesador

Los registros son pequeñas áreas de almacenamiento ubicadas dentro del procesador. Son mucho más rápidos que la memoria principal y se utilizan para guardar datos temporales durante la ejecución de un programa.

AX

Registro acumulador. Se usa frecuentemente en operaciones aritméticas.

BX

Registro base. Puede utilizarse para guardar datos o direcciones.

CX

Registro contador. Es común usarlo en ciclos o repeticiones.

Instrucciones Básicas en Ensamblador

Las instrucciones son órdenes que el procesador ejecuta. Cada instrucción realiza una operación específica sobre registros, memoria o datos.

Instrucción Función
MOV Mueve o copia un dato hacia un registro o posición de memoria.
ADD Suma dos valores.
SUB Resta dos valores.
CMP Compara dos valores.
JMP Realiza un salto hacia otra parte del programa.

Ejemplo Básico en Ensamblador 8086

El siguiente ejemplo coloca valores en dos registros y luego los suma. 

MOV AX, 5
MOV BX, 3
ADD AX, BX

Primero se coloca el valor 5 en el registro AX. Luego se coloca el valor 3 en el registro BX. Finalmente, la instrucción ADD suma BX con AX y deja el resultado almacenado en AX.

Importancia de Programar a Bajo Nivel

Programar a bajo nivel ayuda a comprender cómo se ejecutan realmente las instrucciones dentro del procesador. También permite analizar el uso de registros, memoria, ciclos de instrucción y operaciones internas.

Aunque actualmente se usan lenguajes de alto nivel, el ensamblador sigue siendo útil para estudiar arquitectura de computadoras, optimización, sistemas embebidos y funcionamiento interno de la CPU.

4. Completa la instrucción para sumar AX y BX:

________ AX, BX

Correcto: la instrucción “ADD” es adecuada.

Retroalimentación: ADD permite sumar dos valores. En este caso suma BX con AX.

Incorrecto. La respuesta correcta es: ADD.

Retroalimentación: MOV mueve datos, SUB resta y ADD suma. Para sumar AX y BX se utiliza ADD AX, BX.

5. Completa la instrucción para mover el valor 10 al registro AX:

________ AX, 10

Correcto: la instrucción “MOV” es adecuada.

Retroalimentación: MOV permite cargar o copiar un dato hacia un registro.

Incorrecto. La respuesta correcta es: MOV.

Retroalimentación: para colocar un valor dentro de un registro se utiliza la instrucción MOV.
