Relación con Arquitectura de Máquinas

Arduino representa un sistema basado en microcontrolador. El programa se carga en memoria, el procesador interno ejecuta instrucciones y los pines de entrada o salida permiten interactuar con componentes físicos.

¿Qué ocurre cuando se ejecuta el programa?

La función setup() se usa para configurar el hardware. Por ejemplo, pinMode(13, OUTPUT) indica que el pin 13 funcionará como salida.

La función loop() se repite continuamente. Cuando se ejecuta digitalWrite(13, HIGH), el pin 13 envía una señal alta. Si el LED está conectado correctamente a ese pin y a tierra, el LED se enciende.

Cuando se ejecuta digitalWrite(13, LOW), el pin deja de entregar la señal alta y el LED se apaga. La instrucción delay() controla el tiempo de espera entre un estado y otro.

Limitación del simulador

Este laboratorio es una versión educativa básica. No compila C++ real como el IDE de Arduino ni simula electricidad completa como Tinkercad. Sin embargo, permite manipular componentes, crear cables y probar lógica básica de salida digital, suficiente para demostrar microcontroladores dentro del proyecto.

Para prácticas más completas se recomienda usar Tinkercad Circuits, porque permite trabajar con más componentes electrónicos, protoboard, sensores, motores y una simulación más cercana a un laboratorio real.
