Tutorial de instalación

Instalación de emu8086 y Uso de Tinkercad con Arduino

En esta sección aprenderás cómo instalar y utilizar emu8086 para practicar programación en ensamblador, y cómo usar Tinkercad Circuits para simular proyectos básicos con Arduino.

Tutorial 1: Instalación de emu8086

emu8086 es un emulador utilizado para escribir, compilar y ejecutar programas en lenguaje ensamblador para el microprocesador 8086. Es útil para aprender cómo funcionan los registros, instrucciones y operaciones básicas de bajo nivel.

¿Para qué sirve emu8086?

Sirve para practicar instrucciones como MOV, ADD, SUB, CMP y JMP. También permite observar cómo cambian los registros internos del procesador durante la ejecución de un programa.

Descargar emu8086

Para realizar la práctica, puedes descargar el archivo comprimido de emu8086 desde la carpeta de Google Drive preparada para este proyecto.

Descargar emu8086 desde Google Drive

Nota: después de descargar el archivo comprimido, debes extraerlo antes de ejecutar el instalador.

Pasos para instalar emu8086

  1. Entra al enlace de Google Drive y descarga el archivo comprimido de emu8086.
  2. Espera a que finalice la descarga del archivo.
  3. Busca el archivo comprimido en la carpeta de descargas de tu computadora.
  4. Haz clic derecho sobre el archivo y selecciona la opción para extraerlo.
  5. Abre la carpeta extraída.
  6. Ejecuta el instalador de emu8086.
  7. Acepta los términos de instalación si el programa los solicita.
  8. Selecciona la carpeta donde se instalará el programa.
  9. Espera a que finalice el proceso de instalación.
  10. Abre emu8086 desde el acceso directo del escritorio o desde el menú de inicio.

Recomendación

Guarda el archivo comprimido en una carpeta fácil de encontrar para evitar problemas al momento de instalarlo.

Precaución

Antes de ejecutar cualquier instalador, verifica que el archivo se haya descargado correctamente y que provenga del enlace indicado para la clase.

Cómo usar emu8086

Después de instalar emu8086, puedes crear un programa básico en ensamblador para observar cómo se ejecutan las instrucciones dentro del microprocesador.

Pasos para crear un programa

  1. Abrir el programa emu8086.
  2. Seleccionar la opción para crear un nuevo archivo.
  3. Elegir una plantilla vacía o un ejemplo básico.
  4. Escribir las instrucciones en lenguaje ensamblador.
  5. Compilar el programa para verificar errores.
  6. Ejecutar el programa completo o paso a paso.
  7. Observar los cambios en los registros como AX, BX, CX y DX.

Ejemplo básico en emu8086

MOV AX, 5
MOV BX, 3
ADD AX, BX

En este ejemplo, primero se guarda el número 5 en el registro AX. Luego se guarda el número 3 en el registro BX. Finalmente, la instrucción ADD AX, BX suma ambos valores y deja el resultado dentro de AX.

Explicación del código

Instrucción Función
MOV AX, 5 Coloca el valor 5 en el registro AX.
MOV BX, 3 Coloca el valor 3 en el registro BX.
ADD AX, BX Suma AX con BX y guarda el resultado en AX.

Tutorial 2: Uso de Tinkercad Circuits con Arduino

Tinkercad Circuits es una herramienta en línea que permite crear circuitos electrónicos y simular su funcionamiento. Es muy útil para practicar con Arduino sin necesidad de tener una placa física.

¿Qué se puede hacer con Tinkercad?

Crear circuitos

Puedes arrastrar componentes como resistencias, LEDs, cables, protoboards y placas Arduino.

Programar Arduino

Puedes escribir código para controlar los pines de Arduino y simular su comportamiento.

Simular proyectos

Puedes iniciar una simulación para comprobar si el circuito y el código funcionan correctamente.

Pasos para usar Tinkercad con Arduino

  1. Entra a la página oficial de Tinkercad desde el navegador.
  2. Crea una cuenta o inicia sesión con una cuenta existente.
  3. Busca el apartado llamado Circuits o Circuitos.
  4. Selecciona la opción Create new Circuit o Crear nuevo circuito.
  5. En la lista de componentes, busca Arduino Uno R3.
  6. Arrastra el Arduino al área de trabajo.
  7. Agrega los componentes necesarios, por ejemplo un LED y una resistencia.
  8. Conecta los componentes usando cables virtuales.
  9. Abre el editor de código.
  10. Escribe o pega el código del proyecto.
  11. Presiona Start Simulation para probar el funcionamiento.

Ejemplo: Encender y apagar un LED con Arduino

Este ejemplo simula el parpadeo de un LED conectado al pin 13 de Arduino. Es uno de los ejercicios más básicos para comprender salidas digitales.

Componentes necesarios en Tinkercad

  • 1 Arduino Uno R3.
  • 1 LED.
  • 1 resistencia.
  • Cables de conexión.
  • Opcionalmente, una protoboard.

Conexión básica

Componente Conexión
Pin positivo del LED Conectado al pin digital 13 mediante una resistencia.
Pin negativo del LED Conectado a GND.
Arduino Controla el encendido y apagado del LED.

Código de Arduino

void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  digitalWrite(13, HIGH);
  delay(1000);

  digitalWrite(13, LOW);
  delay(1000);
}

Explicación del código

Línea Explicación
pinMode(13, OUTPUT); Configura el pin 13 como salida.
digitalWrite(13, HIGH); Envía una señal alta al pin 13 y enciende el LED.
delay(1000); Espera un segundo.
digitalWrite(13, LOW); Apaga el LED.

¿Cómo funciona la simulación?

La simulación permite probar el circuito como si estuviera armado físicamente. Cuando se presiona el botón de iniciar simulación, Tinkercad ejecuta el código de Arduino y muestra el comportamiento de los componentes conectados.

Si el código está correcto y las conexiones están bien hechas, el LED se encenderá y apagará cada segundo. Si algo falla, se debe revisar el código, los pines, la polaridad del LED y la conexión a tierra.

Ventaja

Puedes practicar sin tener componentes físicos y corregir errores antes de construir el circuito real.

Limitación

Aunque la simulación ayuda mucho, un circuito real puede tener errores físicos como cables dañados, mala conexión o problemas de alimentación.
