Unidad IV

Arquitectura de los Microcontroladores

En esta unidad se estudia la arquitectura interna de los microcontroladores, sus tipos principales y las diferencias entre Harvard, Von Neumann, CISC y RISC.

4.1 Arquitectura de los Microcontroladores

Un microcontrolador es un circuito integrado que contiene dentro de un mismo chip varios componentes necesarios para controlar dispositivos electrónicos. Normalmente incluye CPU, memoria, puertos de entrada y salida, temporizadores y módulos de comunicación.

A diferencia de un microprocesador, el microcontrolador está diseñado para tareas específicas. Por eso se utiliza mucho en sistemas embebidos, automatización, robótica, sensores, alarmas, electrodomésticos y dispositivos de control.

4.1.1 Diferentes Tipos de Microcontroladores

4.1.1.1 Microcontroladores Embebidos

Los microcontroladores embebidos están integrados dentro de un sistema diseñado para cumplir una función específica. No se usan como una computadora general, sino como controladores de tareas concretas.

Ejemplos de uso son lavadoras, controles remotos, alarmas, sensores de temperatura, sistemas automotrices, impresoras, juguetes electrónicos y dispositivos médicos.

4.1.1.2 Microcontrolador con Memoria Externa

Algunos microcontroladores permiten conectarse a memoria externa cuando la memoria interna no es suficiente. Esto se usa cuando el programa es más grande o cuando se necesita almacenar más datos.

Microcontrolador embebido

Está pensado para controlar una tarea específica dentro de un sistema electrónico.

Con memoria externa

Puede ampliar su capacidad usando memoria adicional fuera del chip.

4.1.2 Arquitectura de Microcontroladores

4.1.2.1 Harvard vs Von Neumann

La arquitectura Harvard y la arquitectura Von Neumann describen la forma en que el sistema organiza la memoria para guardar datos e instrucciones.

Arquitectura Característica Ventaja
Harvard Separa la memoria de datos y la memoria de instrucciones. Puede acceder a datos e instrucciones al mismo tiempo.
Von Neumann Usa una sola memoria para datos e instrucciones. Su diseño es más simple y flexible.

4.1.2.2 CISC vs RISC

CISC y RISC son enfoques de diseño del conjunto de instrucciones del procesador. Se diferencian principalmente por la complejidad y cantidad de instrucciones.

CISC

Significa computadora con conjunto complejo de instrucciones. Posee instrucciones más completas, pero algunas pueden tardar más ciclos en ejecutarse.

RISC

Significa computadora con conjunto reducido de instrucciones. Usa instrucciones simples, rápidas y eficientes.

Importancia de la Arquitectura en Microcontroladores

Conocer la arquitectura de un microcontrolador permite seleccionar el dispositivo adecuado para cada proyecto. Por ejemplo, un sistema de bajo consumo puede necesitar un microcontrolador pequeño y eficiente, mientras que un proyecto más complejo puede requerir más memoria, más puertos o mayor velocidad.
