Arquitectura de Computadoras, Microprocesadores y Microcontroladores

Página educativa creada para explicar los principales conceptos de la asignatura Arquitectura de Máquinas, integrando teoría, ejemplos prácticos, tutoriales, simulación de Arduino y quizzes de repaso por unidad.

Explora las unidades de la clase

Cada unidad está separada en su propia página para facilitar la lectura. Al final de cada tema encontrarás un quiz de repaso con retroalimentación.

01

Unidad I

Introducción a los microprocesadores y microcontroladores. Arquitectura, organización, estructura y diferencias principales.

02

Unidad II

Arquitectura del microprocesador, modelo Von Neumann, buses, terminales, memoria, periféricos, 8255 y 8259.

03

Unidad III

Programación del microprocesador con instrucciones básicas en lenguaje ensamblador.

04

Unidad IV

Arquitectura de microcontroladores, tipos, Harvard vs Von Neumann, CISC y RISC.

05

Unidad V

Programadores del microcontrolador, proceso de carga, herramientas y pruebas.

06

Tutoriales

Tutorial básico de emu8086 y Arduino con ejemplos prácticos para reforzar el aprendizaje.

07

Arduino

Simulador educativo para conectar un circuito básico con Arduino, escribir lógica estilo C++ y observar el funcionamiento de un LED.

Objetivo

Aprender teoría y práctica en una sola web

Explicaciones claras

Los temas se explican con lenguaje sencillo para comprender la función de cada componente dentro de la computadora.

Ejemplos prácticos

Se incluyen ejemplos de código y situaciones reales para conectar la teoría con la práctica.

Quizzes y simulación

Cada unidad tiene ejercicios de repaso y ahora se incluye una sección de Arduino para visualizar el funcionamiento de un microcontrolador.
